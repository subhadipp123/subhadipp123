### 🎧 AcousticSpace — Deepfake Audio Detection

An audio analysis project that classifies speech as **bonafide or spoof**, combining acoustic analysis, a **CNN baseline**, and a frozen **Audio Spectrogram Transformer (AST)** feature extractor with a trained binary classifier.

- Uses the **ASVspoof 2019 Logical Access** dataset to classify genuine and spoofed speech.
- Implements audio preprocessing and feature extraction with Librosa, including resampling, normalization and Mel-spectrogram generation.
- Uses a lightweight CNN baseline and a pretrained AST as a frozen feature extractor to generate 768-dimensional audio embeddings.
- Evaluated both models on 100 samples, achieving 85% accuracy with AST versus 65% with CNN and reducing false positives from 24 to 4.
- Connects a FastAPI backend with a React interface and uses Docker Compose for the application setup.

**Technologies:** Python · PyTorch · Librosa · FastAPI · React · Docker

**[View Repository →](https://github.com/subhadipp123/AcousticSpace)**
